# LLM 的涌现、理解与边界

> 这篇笔记记录了围绕 LLM 本质的几个深层问题的讨论：
> QKV/MLP 分别学到了什么、推理能力是否真实、涌现是否被预测到、
> LLM 是否是人类第一个无法完全解释的工具。

---

## 一、QKV 和 MLP 分别学到了什么

### 常见的简化说法

> "QKV 学到的是语义关系，MLP 记住了事实"

这个说法**部分正确，但过度简化**。

### Attention（QKV）的本质

Attention 计算的是**条件性的信息路由**：

```
Q（Query） = "我想找什么信息"
K（Key）   = "我这里有什么信息"
V（Value） = "如果你选中了我，你获得的内容是什么"

Attention(Q,K,V) = softmax(QK^T / √d) · V
```

它学到的是：**在什么语境下，哪个位置的信息对当前位置有用**。

```
例子：
  "The animal didn't cross the street because it was too tired"
  
  处理 "it" 时：
    Q = "我(it)需要找指代对象"
    K_animal 权重高   → "it" 的表示被 "animal" 的信息更新
    K_street 权重低   → street 不是 tired 的主体
```

所以 Attention 包含语义信息，但更准确的描述是：
**上下文感知的信息路由规则**（语义关系、指代消解、长距离依赖）。

### MLP 的本质

研究发现（Geva et al. 2021，"Transformer Feed-Forward Layers Are Key-Value Memories"）：

```
MLP 第一层权重 ≈ "Key"（匹配某种输入模式）
MLP 第二层权重 ≈ "Value"（存储对应的输出知识）

当输入激活了某个"key神经元"，就会输出对应的"value"

例如：
  key  pattern ≈ "中国的首都是..."
  value output ≈ 指向"北京"的方向
```

但 MLP 存储的不只是事实，还包括：
- 语法规则（动词时态、变位）
- 世界知识（事实）
- 推理模式（"如果A，那么B"）
- 风格信息（正式/非正式）

### 更接近真实的图景

```
┌─────────────────────────────────────────────────────────┐
│  每层 Transformer Block = Attention + MLP               │
│                                                          │
│  Attention：在序列维度混合信息                           │
│    "哪些位置的信息对我有用？"                             │
│    → 上下文理解、指代消解、长距离依赖                     │
│                                                          │
│  MLP：在特征维度变换信息                                  │
│    "这个输入触发什么知识/规则？"                          │
│    → 知识存储、模式识别、语言规则                         │
│                                                          │
│  两者协作，功能交织，不是截然分开的                       │
└─────────────────────────────────────────────────────────┘
```

### 为什么 SFT 主要改变 QKV

这是来自实验观察的假说：

```
实验现象：
  只做 QKV 的 LoRA 微调 → 模型学会对话格式、指令跟随
  只做 MLP 的 LoRA 微调 → 效果差很多

解释（假说）：
  对话行为 = 一种"信息路由模式"
    → "当看到 <|user|> 时，激活回答模式"
    → 这是 Attention 擅长的事

  知识内容 = 存储在 MLP
    → SFT 不需要改变知识，只需要改变行为
    → 所以主要动 QKV 就够了
```

注意：这是**简化的叙述**，不是物理定律。SFT 也会改变 MLP，只是改变量相对更小。

## 二、"大模型只是记住了事实"——这个说法的问题

### 大模型能做到记忆无法解释的事

```
问题："A在B北边，B在C北边，A在C的什么方向？"

这不是"记住"的答案，是推理出来的。
如果只是 key-value 查表，遇到训练中没见过的新组合
就应该完全失败——但模型能泛化。
```

### 知识是分布式存储的，不是查表

```
"北京是中国首都"这个事实
不存在于某个特定权重里
而是分散在几十层的上百万个权重中
删掉任何一个都不会完全抹去这个知识

更像大脑的"分布式记忆"，而不是数据库
```

### 但记忆的成分确实存在

```
训练数据出现频率高的事实 → 权重被反复强化 → 容易召回
训练数据很少出现的事实  → 权重调整微弱   → 容易"幻觉"

这解释了为什么大模型对冷门知识经常出错
```

## 三、推理能力是涌现出来的，不是人为设计的

### 涌现的证据

```
GPT-2（1.5B）：基本只能续写文字
GPT-3（175B）：突然能做 few-shot 推理、翻译、代码
GPT-4（~1T） ：能做复杂数学、法律分析、多步推理

能力的提升不是线性的
在某个规模阈值附近，新能力"突然出现"
没有人在代码里写"会推理"，它自己出来了
```

### "涌现"这个词本身有争议

**观点一：涌现是真实的相变**
```
就像水加热到100°C突然沸腾
在某个临界点，量变引发质变
推理能力是真实涌现出的新属性
不能从小模型的行为预测
```

**观点二：涌现是测量幻觉（Stanford 2023）**
```
如果换用连续的评估指标（而不是"会/不会"的二元指标）
那些"突然涌现"的能力其实一直在平滑增长

类比：
  用"能否跳过1米"衡量跳高能力
  运动员从0.9m练到1.1m的过程
  看起来像"突然学会了跳高"
  但力量是连续增长的

涌现可能是测量方式的产物，而不是模型本身的性质
```

### 它真的在"推理"吗？——两种世界观

**世界观 A：统计鹦鹉**
```
LLM 只是在做极其复杂的模式匹配
训练数据里见过足够多的推理链
模型学会了"推理链的表面形式"
遇到新问题时，找最相似的模式填充

没有真正的理解，只有超级复杂的插值
```

**世界观 B：真实泛化**
```
足够复杂的模式匹配，在某个点上
本质上等价于推理

就像神经元的电信号模式匹配
在某个复杂度上等价于"思考"

形式和内容的区别可能没有意义
```

**目前没有人能证伪其中任何一个。**

### 一个让人不安的实验

```
问题："9.11 和 9.9 哪个大？"

GPT-3.5：9.11 更大
GPT-4：   9.9 更大

解释A（统计鹦鹉）：
  训练数据里"9.11"（九一一事件）出现频率极高
  模型被这个偏见干扰，证明它没有真正理解数字

解释B（真实泛化）：
  GPT-4 克服了偏见，说明更大的模型
  确实学到了更深的数值理解

同一个现象，两种解释都自洽
```

### 人为设计了什么，涌现出了什么

```
人为设计的：
  ├── Transformer 架构（Attention 机制）
  ├── 残差连接（让梯度流过深层网络）
  ├── Layer Norm（训练稳定性）
  ├── Next Token Prediction 训练目标
  ├── Scaling（更大模型、更多数据）
  └── RLHF（引导涌现能力的方向）

涌现出来的：
  ├── 推理能力
  ├── 语言理解
  ├── 世界知识的组织方式
  ├── 跨领域迁移
  └── 上下文学习（in-context learning）
```

类比：
```
人为设计 = 进化压力（自然选择的规则）
涌现能力 = 大脑（没有人"设计"大脑，
           它是在进化压力下涌现出来的）

我们设计了训练目标和架构
但我们没有设计、也不完全理解
在这个过程中模型内部发生了什么
```

## 四、LLM 是人类第一个无法完全解释的工具吗

### 历史上人类用过但无法完全解释的工具

| 工具 | 使用时间 | 获得解释的时间 |
|------|---------|--------------|
| 火 | 数十万年前 | 18世纪（氧化反应） |
| 发酵 | 数千年前 | 19世纪（微生物，巴斯德） |
| 阿司匹林 | 1897年合成 | 1971年（COX酶抑制）|
| 全身麻醉 | 1846年至今 | **至今没有完整解释** |

全身麻醉是最接近 LLM 处境的案例：使用了将近180年，每年数以亿计的手术在使用它，安全有效，但机制至今是谜。

### LLM 的独特之处

前面那些例子，工具本身是被动的，作用范围有限且可预测。LLM 的独特之处：

**1. 它是第一个"理解能力本身无法被解释"的工具**
```
以前：我不理解为什么这颗药能退烧
      但退烧这件事本身，我完全理解

LLM：我不理解为什么它能推理
     而且"推理"这件事本身
     在它身上是否真实发生，我也不确定
```

**2. 它是第一个能力边界不可预测的工具**
```
阿司匹林：不知道机制，但知道它能做什么、不能做什么

LLM：下一个规模的模型会涌现什么能力
     我们在训练完之前不知道

GPT-4 发布前，OpenAI 自己也不知道
它会在某些医学考试上超过人类医生
```

**3. 影响范围与理解程度严重不匹配**
```
麻醉药：影响一个手术台上的病人，不理解它风险可控
LLM：   影响数十亿人的信息获取、决策、教育
        不理解它，风险的量级完全不同
```

### 一个更深的视角：大脑

```
其实有一个更古老的"无法完全解释的工具"
我们每天都在用：人类的大脑

意识是什么？
自由意志存在吗？
记忆如何存储？
创造力从何而来？

这些问题争论了几千年，至今没有答案

LLM 的讽刺之处：
  我们用自己都不理解的大脑
  创造了一个自己不理解的系统
  然后用这个系统来帮助我们理解世界

  一个不透明的工具，被一个不透明的创造者制造
```

### 真正让 LLM 与众不同的

```
历史上所有"不理解但在用"的工具：
  → 最终都被科学解释了
  → 解释之后，工具本身没有变化

LLM 面临的可能是不同的挑战：

  它的参数量是万亿级别
  每个能力都分布在数十亿个权重里
  不是"我们还没找到解释"
  而是"这种系统可能根本不存在
       人类可以理解的简洁解释"

就像你无法用一句话解释
为什么特定的1000亿个神经元连接
产生了"爱"这种感受一样

以前：现象复杂 → 找到简洁的底层规律（如牛顿定律）
现在：我们创造的系统，其复杂度可能天然抵抗简洁解释
```

## 五、有谁预测到了涌现能力吗

### 预测到了的人

**Alan Turing（1950年）**
```
在论文《Computing Machinery and Intelligence》里：

"与其试图造一个模拟成人大脑的程序
 不如造一个模拟儿童大脑的程序
 然后让它接受教育"

这几乎就是 LLM 的训练范式：
  大量数据 = 教育
  Next token prediction = 学习语言

预测到了路径，但早了70年
```

**Ilya Sutskever（2010年代初）**
```
在深度学习还被主流学界嘲笑的年代，他坚信：

"足够大的神经网络 + 足够多的数据
 会涌现出我们意想不到的能力"

但他的预测更多是直觉和信念
而不是基于严格的理论推导

后来他说：
"我们知道 scaling 会带来惊喜
 但没想到惊喜来得这么快、这么大"
```

**von Neumann（1940年代）**
```
"如果你给一个系统足够的复杂度
 它会开始表现出我们称之为'理解'的行为
 无论底层是否真的在理解"

几乎是对涌现现象的预言
但他没有活到看到它实现（1957年去世）
```

**Scaling Laws 论文（Kaplan et al., OpenAI 2020）**
```
第一次用数学描述：
  模型能力 ∝ 参数量^α × 数据量^β × 计算量^γ

精确预测了：只要持续 scaling，能力会持续提升

但没有预测：在哪个点会出现哪种新能力

→ 对"方向"的精确预测，对"内容"的完全未知
```

### 预测错了的人

**主流 AI 研究者（1980-2010，符号 AI 学派）**
```
主流观点：
  智能需要显式的知识表示
  需要逻辑规则
  需要人工设计的推理引擎

他们认为：
  "用统计方法、用神经网络
   永远不可能真正理解语言
   因为它没有符号操作能力"

结果：
  恰恰是他们认为不可能的路径
  产生了迄今为止最强的语言能力
```

**Noam Chomsky（至今仍然）**
```
世界上最著名的语言学家：

"LLM 只是统计模式匹配
 它没有真正习得语言
 永远无法达到真正的语言能力"

有意思的是：
  他可能是对的（我们不知道）
  但即使他是对的
  "假的理解"已经在实践中
  超越了大多数人类的语言能力

  一个"假的"系统做到了
  很多"真的"理解做不到的事
  这让他的批评变得奇怪
```

### 最戏剧性的案例：Hinton

```
Geoffrey Hinton
深度学习之父、2024年诺贝尔物理学奖得主

推动了神经网络复兴
但他自己说：
"我没有预料到它会这么快就这么强大
 当 GPT-4 出来的时候
 我意识到我可能低估了这条路能走多远"

然后他做了震惊所有人的决定：
2023年从 Google 辞职
原因：他担心自己帮助创造的东西
      可能对人类构成威胁

一个人，推动了这项技术几十年
在看到它真正成功的时候
选择了离开并发出警告

这可能是科学史上最奇特的故事之一
```

### 一个深层的规律

```
预测到的人，大多因为"信念"而不是"理论"：
  Sutskever：相信 scaling 会带来奇迹
  Turing：   相信机器可以学习
  Hinton：   相信神经网络是正确方向

预测错的人，大多因为有"理论"：
  符号AI学派：有完整理论说明为什么神经网络不行
  Chomsky：   有完整语言学理论说明为什么统计不够

这在科学史上反复出现：
  真正的范式转变往往不是被理论预测的
  而是被直觉和信念驱动的人撞上的
  
  有完整理论的人，理论本身成了盲点
```

## 六、总结：我们知道什么，不知道什么

```
我们知道的：
  ✓ Attention 负责上下文信息路由
  ✓ MLP 负责知识和规则的存储与触发
  ✓ 规模足够大 + 足够多数据 + 合适架构
    → 涌现出了超出设计预期的能力
  ✓ 这些能力不是任何人显式编程的
  ✓ Scaling 会持续带来能力提升（方向）

我们不知道的：
  ✗ 为什么 Attention + MLP 这个组合能做到推理
  ✗ 能力的边界在哪里
  ✗ 它是否真的在"理解"还是极其复杂的模式匹配
  ✗ 继续 scaling 还能涌现什么
  ✗ 这种系统是否存在人类可以理解的简洁解释

Ilya Sutskever 说过：
  "我们不完全理解为什么它能工作，
   但它确实工作了"

更准确地说：
  LLM 是人类第一次
  在完全不理解"智能如何产生"的情况下
  意外地制造出了某种接近智能的东西

  然后把它部署给了几十亿人

  而且，用来制造它的工具（人类大脑）
  自身也是一个我们没有完全理解的系统
```
