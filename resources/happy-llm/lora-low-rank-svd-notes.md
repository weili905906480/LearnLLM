# LoRA、低秩分解与 SVD 学习笔记

这份笔记整理 LoRA 微调的底层数学直觉，重点解释为什么 LoRA 可以用两个小矩阵表示大模型权重的任务修正量，以及 SVD 与低秩近似在其中提供了怎样的数学背景。

## 1. LoRA 微调在改什么

Transformer 中大量参数来自线性层。一个线性层可以写成：

```text
y = W x
```

其中：

- `x` 是输入向量。
- `W` 是预训练阶段学好的权重矩阵。
- `y` 是输出向量。

普通全量微调会直接更新 `W`：

```text
W -> W + ΔW
```

也就是让模型为新任务学习一个完整的权重变化量 `ΔW`。问题是大模型中的 `W` 通常非常大，比如 `4096 x 4096` 的矩阵就有 1600 多万个参数。如果每个大矩阵都全量更新，显存、优化器状态和 checkpoint 存储都会很重。

LoRA 的做法是冻结原始权重 `W`，只额外训练一个小的修正项：

```text
y = W x + ΔW x
```

并进一步约束：

```text
ΔW = B A
```

所以 LoRA 的前向传播是：

```text
y = W x + B A x
```

训练时：

- `W` 不更新。
- `A` 和 `B` 是微调时新增的小矩阵。
- 只训练 `A` 和 `B`。

## 2. 这两个矩阵预训练时有吗

一般没有。

标准预训练模型的线性层只有原始权重：

```text
y = W x
```

LoRA 微调时才为某些线性层外挂两个 adapter 矩阵：

```text
y = W x + B A x
```

这两个矩阵不是基座模型预训练阶段自带的参数，而是微调时临时插入的参数。常见初始化方式是：

```text
A 随机初始化
B 初始化为 0
```

这样训练刚开始时：

```text
B A x = 0
```

模型行为和原始基座模型完全一致。随着训练进行，`A` 和 `B` 学出当前任务需要的修正量。

## 3. `ΔW = B A` 的数学含义

假设原权重矩阵是：

```text
W ∈ R^{d_out × d_in}
```

完整微调要学习：

```text
ΔW ∈ R^{d_out × d_in}
```

LoRA 不直接学习完整 `ΔW`，而是令：

```text
A ∈ R^{r × d_in}
B ∈ R^{d_out × r}
ΔW = B A
```

其中 `r` 是一个很小的数，比如 4、8、16、64。

矩阵乘法有一个重要性质：

```text
rank(B A) ≤ r
```

也就是说，LoRA 把 `ΔW` 限制成一个秩最多为 `r` 的低秩矩阵。

直观理解：

```text
x -> A x -> B(Ax)
```

`A` 先把输入从高维压到 `r` 维，提取少数任务相关方向；`B` 再把这 `r` 个方向映射回输出空间。LoRA 不是允许模型在所有方向上任意修改，而是让模型只通过一个低维通道学习任务修正。

## 4. 为什么低秩更新可能有效

LoRA 的关键假设是：

```text
大模型预训练后已经具备大量通用能力。
针对具体任务微调时，不需要重塑全部参数，
只需要在少数关键方向上调整模型行为。
```

例如：

- 学会某种回答格式。
- 适配某个领域术语。
- 强化某类问答模式。
- 调整指令遵循风格。

这些变化可能不需要一个满秩的 `ΔW`，一个低秩修正矩阵已经足够表达主要变化。

参数量对比也体现了这个约束的价值。

完整更新：

```text
参数量 = d_out * d_in
```

LoRA 更新：

```text
参数量 = r * d_in + d_out * r
     = r(d_in + d_out)
```

如果：

```text
d_in = d_out = 4096
r = 8
```

完整 `ΔW` 参数量：

```text
4096 * 4096 = 16,777,216
```

LoRA 参数量：

```text
8 * (4096 + 4096) = 65,536
```

只有原来的约 `0.39%`。

## 5. SVD 是什么

SVD 全称是 Singular Value Decomposition，中文叫奇异值分解。

它说明任何矩阵都可以拆成三个矩阵相乘：

```text
W = U Σ V^T
```

可以把它理解成一个线性变换的三步分解：

```text
y = W x = U Σ V^T x
```

第一步：

```text
V^T x
```

把输入旋转或变换到一组特殊坐标轴上。

第二步：

```text
Σ(...)
```

沿不同方向进行缩放。

第三步：

```text
U(...)
```

把结果旋转或变换到输出空间。

其中 `Σ` 是对角矩阵：

```text
Σ =
[σ1  0   0
 0   σ2  0
 0   0   σ3]
```

这些 `σ` 叫奇异值，通常从大到小排列：

```text
σ1 ≥ σ2 ≥ σ3 ≥ ...
```

奇异值越大，说明对应方向越重要；奇异值越小，说明对应方向对矩阵整体作用越弱。

## 6. SVD 如何产生低秩近似

如果一个矩阵的奇异值大致是：

```text
100, 50, 20, 0.3, 0.1, 0.01
```

说明前 3 个方向贡献最大，后面的方向影响很小。可以只保留前 `r` 个奇异值：

```text
W ≈ U_r Σ_r V_r^T
```

这就是低秩近似。

更具体地，如果保留前 `r` 个奇异值：

```text
W_r = U_r Σ_r V_r^T
```

那么 `W_r` 是秩为 `r` 的近似矩阵。经典线性代数中，截断 SVD 给出了在常用误差度量下的最佳秩 `r` 近似。

## 7. SVD 和 LoRA 的关系

LoRA 不会先求出完整 `ΔW`，再对它做 SVD。实际训练时，LoRA 是直接训练 `A` 和 `B`。

但 SVD 提供了一个很好的数学直觉：

如果某个完整权重变化可以写成：

```text
ΔW = U Σ V^T
```

而它的主要信息集中在前 `r` 个奇异值上，那么可以近似为：

```text
ΔW_r = U_r Σ_r V_r^T
```

这个低秩近似可以写成两个矩阵相乘：

```text
ΔW_r = B A
```

例如：

```text
B = U_r Σ_r
A = V_r^T
```

这说明 `B A` 的形式天然可以表达一个低秩矩阵。LoRA 的训练过程就是让 `A` 和 `B` 自己学出一个对任务有用的低秩更新。

## 8. 通俗总结

可以把预训练模型想成一本已经写好的厚书。

全量微调是直接修改整本书：

```text
W -> W + ΔW
```

LoRA 是不改原书，只贴少量任务相关便利贴：

```text
y = W x + B A x
```

这些便利贴数量很少，但如果贴在关键位置，就能明显改变模型在某类任务上的表现。

从数学上看：

```text
LoRA = 用低秩矩阵分解约束权重更新。
```

核心公式是：

```text
ΔW = B A
rank(B A) ≤ r
```

核心直觉是：

```text
微调所需的变化不是任意复杂的大矩阵，
而可能主要集中在少数关键方向上。
```

SVD 则解释了为什么一个复杂矩阵常常可以用少数重要方向近似表示：

```text
W = U Σ V^T
只保留最大的 r 个奇异值
W ≈ U_r Σ_r V_r^T
```

这就是 LoRA 背后“低秩更新”的数学基础。
