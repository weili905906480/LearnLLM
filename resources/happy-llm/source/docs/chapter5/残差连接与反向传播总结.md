# Transformer 残差连接与反向传播总结

本文总结 Transformer 中残差连接的直观含义，以及它在反向传播时为什么能缓解梯度消失问题。

## 1. 残差连接是什么

Transformer 的一个子层通常不是直接输出：

```text
y = F(x)
```

而是输出：

```text
y = x + F(x)
```

其中：

- `x` 是进入当前子层之前的输入表示。
- `F(x)` 是当前子层学到的新变换，例如 Attention 或 FFN。
- `y` 是把原始表示和新变换合并后的结果。

通俗理解：

```text
x    = 原文
F(x) = 批注
y    = 原文 + 批注
```

每一层不需要完全重写输入表示，而是在已有表示上做补充和修正。

## 2. 输入 x 会被直接修改吗

数学上通常写成：

```text
y = x + F(x)
```

这表示产生了一个新的输出 `y`，不是把原来的 `x` 原地改掉。

代码里经常会看到：

```python
x = x + F(x)
```

这只是把变量名 `x` 重新绑定到新的张量结果上，方便继续传给下一层。残差连接本身并不是在原地修改旧的输入张量。

训练时，优化器更新的是模型参数，例如 Attention、FFN 或 Embedding 中的权重。普通输入张量本身通常不会被优化器直接更新。

## 3. 残差连接为什么会影响 W 的训练

假设当前子层是一个简单线性变换：

```text
F(x) = Wx
```

没有残差连接时：

```text
y = Wx
```

有残差连接时：

```text
y = x + Wx
```

在前向传播中，`Wx` 会先被计算出来，然后再和 `x` 相加。这个加法不会回头修改当前已经算好的 `Wx`，也不会直接修改 `W`。

但是在反向传播时，损失函数是根据最终输出 `y` 计算出来的。因此 `W` 的梯度会受到整体结构影响：

```text
L -> y -> F(x) -> W
```

也就是说，残差分支 `x` 不直接经过 `W`，但它参与了最终输出 `y`，所以会间接影响 loss，从而影响 `W` 的梯度。

## 4. 能不能不加 x，而是加一个统一的常数

可以写成：

```text
y = F(x) + c
```

但这不等价于残差连接。

如果 `c` 是常数，它不依赖输入 `x`，那么反向传播时：

```text
dL/dx = dL/dy * dF(x)/dx
```

而标准残差连接：

```text
y = x + F(x)
```

对应：

```text
dL/dx = dL/dy * (1 + dF(x)/dx)
```

关键区别是多出来的 `1`。

这个 `1` 来自输入 `x` 到输出 `y` 的直接路径：

```text
x -> y
```

如果只加常数 `c`，它只能改变输出偏移，更像 bias，不能保留输入信息，也不能给梯度提供从 `y` 直接回到 `x` 的通路。

所以：

```text
加 x：保留原始信息，并提供梯度直通路径。
加常数 c：只改变输出数值偏移，不能提供输入直通路径。
```

如果担心 `x` 的影响过强，可以使用带系数的残差形式：

```text
y = F(x) + alpha * x
```

或者：

```text
y = x + alpha * F(x)
```

其中 `alpha` 可以是固定小值，也可以是可学习参数。

## 5. 为什么加 x 可以缓解梯度消失

没有残差连接时：

```text
y = F(x)
```

反向传播：

```text
dL/dx = dL/dy * dF(x)/dx
```

如果很多层串起来，梯度需要不断乘每一层的导数。如果这些导数经常小于 1，梯度会越来越小。

有残差连接时：

```text
y = x + F(x)
```

反向传播：

```text
dL/dx = dL/dy * (1 + dF(x)/dx)
```

这里的 `1` 就是残差连接带来的直接梯度通路。梯度不必完全穿过复杂的 `F(x)`，可以直接从输出传回输入。

通俗理解：

```text
没有残差连接：
梯度必须穿过每一层复杂模块，容易越传越弱。

有残差连接：
梯度多了一条近路，可以直接传回前面的输入。
```

残差连接不是保证梯度永远不会变小，而是显著降低深层网络中梯度消失的风险。

## 6. 实际数字例子

假设某一层的变换是：

```text
F(x) = 0.2x
```

输入：

```text
x = 10
```

### 6.1 没有残差连接

前向传播：

```text
y = F(x) = 0.2 * 10 = 2
```

反向传播：

```text
dy/dx = 0.2
```

如果从后面传回来的梯度是：

```text
dL/dy = 1
```

那么：

```text
dL/dx = 1 * 0.2 = 0.2
```

如果连续 5 层都类似，每层梯度都乘 `0.2`：

```text
1 -> 0.2 -> 0.04 -> 0.008 -> 0.0016 -> 0.00032
```

梯度很快变得非常小。

### 6.2 有残差连接

前向传播：

```text
y = x + F(x)
y = 10 + 0.2 * 10
y = 12
```

反向传播：

```text
dy/dx = 1 + 0.2 = 1.2
```

如果：

```text
dL/dy = 1
```

那么：

```text
dL/dx = 1 * 1.2 = 1.2
```

连续 5 层时：

```text
1 -> 1.2 -> 1.44 -> 1.728 -> 2.0736 -> 2.48832
```

这个例子说明，残差连接让梯度不再只能依赖 `F(x)` 的导数，而是额外获得了输入 `x` 带来的直接路径。

## 7. 核心结论

Transformer 中残差连接的核心作用是：

```text
前向传播：保留原始输入信息，并在其基础上叠加新特征。
反向传播：提供一条从输出直接回到输入的梯度通路。
```

因此，残差连接既帮助模型更容易学习“增量修改”，也帮助深层网络更稳定地训练。
